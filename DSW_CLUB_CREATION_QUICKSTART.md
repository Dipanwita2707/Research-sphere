# DSW Club Creation - Quick Start Guide 🚀

## For Faculty: How to Create a New Club

### Step-by-Step Process:

#### 1. **Navigate to DSW Dashboard**
```
Login → Navigation Header → Administration → Division of Student Welfare
```

#### 2. **Click "Create New Club" Button**
- Blue button in the top right of the DSW dashboard
- Opens the 6-step Club Creation Form

---

### 3. **Fill Out the 6-Step Form:**

#### **Step 1: Core Club Identity** ⭐
Required fields:
- **Club Name:** Must be unique (e.g., "Robotics Club", "Cultural Society")
- **Category:** Select from dropdown (Technical, Cultural, Sports, etc.)
- **Purpose:** Minimum 50 characters - describe the club's objectives
- **Academic Session:** Format: "2025-2026"

⚠️ **Note:** These fields are **immutable after approval** - changes require new noting

#### **Step 2: Authority & Membership** 👥
- **Faculty Facilitator:** Auto-assigned to you (logged-in user)
- **Vice Chairperson:** 
  - Type at least 3 characters to search
  - Select from dropdown (Student ID, Name, Department shown)
  - Click on student to select
- **Initial Members:**
  - Search students by ID/Name (minimum 3 characters)
  - Click to add multiple founding members
  - Remove with "Remove" button

#### **Step 3: Governance & Compliance** 🛡️
- **Target Student Group:** Select All / UG / PG / PhD
- **Activity Types:** Check at least one:
  - Events, Workshops, Competitions, Awareness Drives, etc.
- **⚠️ MANDATORY Checkboxes (both required):**
  - ✅ Code of Conduct Accepted
  - ✅ Anti-Discrimination Declaration

**Cannot proceed without accepting both compliance declarations!**

#### **Step 4: Operational Planning** 📅
- **Meeting Frequency:** Weekly / Monthly / Event-based
- **Annual Activity Count:** Number (minimum 1)
- **Infrastructure:** Check required facilities:
  - Auditorium, Classroom, Lab, Open Ground, etc.
- **Funding Required:** Toggle on if funding needed
  - If yes, enter estimated amount (₹)

#### **Step 5: Visibility & Collaboration** 🌐
- **Visibility:**
  - **Public:** Discoverable by all students
  - **Restricted:** Invite/approval based
- **Collaboration:**
  - ✅ Allow Internal Clubs: Collaborate with other university clubs
  - ✅ Allow External Organizations: Partner with external bodies

#### **Step 6: Optional Metadata** 📧 (Optional but recommended)
- Proposed Email ID (e.g., roboticsclub@sgtuniversity.org)
- Social Media Handles:
  - Facebook, Instagram, Twitter, LinkedIn
- Expected Student Strength (approximate number of members)

---

### 4. **Submit Request**
- Click **"Submit Request"** button at bottom
- Form validates all 6 steps
- Success: Redirected to Noting details page

---

## What Happens After Submission?

### Noting Workflow:
```
┌──────────────┐
│ You (Faculty)│
│  CREATE      │
└──────┬───────┘
       │
       ▼
┌──────────────┐      ┌──────────────────┐      ┌──────────────┐
│     DSW      │      │     Higher       │      │  Club AUTO-  │
│   REVIEWS    │─────>│    Authority     │─────>│   CREATED    │
│              │      │    APPROVES      │      │  (Active)    │
└──────────────┘      └──────────────────┘      └──────────────┘
```

1. **Noting Created:** Status = Pending
2. **DSW Reviews:** First approval level
3. **Higher Authority:** Final approval
4. **Club Auto-Created:** 
   - Club ID generated (e.g., ROBO-12345ABC)
   - Status = **Active**
   - Initial members added automatically
   - Audit log created

## Common Issues & Solutions

### ❌ "Cannot proceed to next step"
**Solution:** Fill all required fields marked with red asterisk (*)

### ❌ "Student search not working"
**Solution:** Type at least 3 characters (e.g., "21U" or "Raj")

### ❌ "Cannot submit - compliance error"
**Solution:** Check both boxes:
- ✅ Code of Conduct Accepted
- ✅ Anti-Discrimination Declaration

### ❌ "Purpose too short"
**Solution:** Write at least 50 characters describing the club

### ❌ "0 activity types selected"
**Solution:** Check at least one activity type checkbox

---

## Tips for Success 💡

### 1. **Write a Clear Purpose Statement**
Good example:
> "The Robotics Club aims to foster innovation and hands-on learning in robotics and automation. We will conduct workshops on Arduino, IoT, and AI-driven robotics, participate in national competitions, and collaborate with industry partners to provide real-world project experience to students."

Bad example:
> "Robotics club for students interested in robots."

### 2. **Select Appropriate Activity Types**
- Technical clubs: Workshops, Competitions, Collaborations
- Cultural clubs: Events, Cultural Programs, Awareness Drives
- Sports clubs: Events, Competitions, Community Service

### 3. **Realistic Operational Planning**
- **Weekly meetings:** For active clubs with frequent activities
- **Monthly meetings:** For clubs with fewer but impactful events
- **Event-based:** For seasonal or specialized clubs

### 4. **Infrastructure Requirements**
- Be realistic: Don't select all options
- Essential only: What you'll actually use regularly

### 5. **Funding Estimation**
- Break down costs: Equipment, events, travel, materials
- Be reasonable: Match with activity count and goals

## Best Practices ⭐

1. **Plan Before You Start:** Know your club structure before filling the form
2. **Involve Students:** Get VC and initial members' consent beforehand
3. **Clear Objectives:** Write detailed purpose and realistic activity plans
4. **Compliance First:** Ensure all governance requirements are met
5. **Track Your Noting:** Monitor approval progress regularly
6. **Post-Approval:** Activate the club immediately with first meeting
