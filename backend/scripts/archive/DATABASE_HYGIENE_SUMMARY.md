#### 2. Employees Without Department Assignment
- **Issue:** 2 employees have no department assignment (no primary department, school, or central dept)
- **Impact:** Medium - These employees may not appear in department-specific reports
- **Recommendation:** Review these 2 employees and assign them to appropriate departments:
  ```sql
  -- Find unassigned employees
  SELECT ul.uid, ul.email, ed.first_name, ed.last_name
  FROM employee_details ed
  JOIN user_login ul ON ul.id = ed.user_login_id
  WHERE ed.primary_department_id IS NULL 
    AND ed.primary_school_id IS NULL 
    AND ed.primary_central_dept_id IS NULL;
  ```

#### 3. Faculty/Staff Without Permissions
- **Issue:** 26 faculty/staff users don't have active department permissions
- **Impact:** High - These users may not be able to access department-specific features
- **Recommendation:** Review and assign appropriate permissions to these 26 users:
  ```sql
  -- Find users without permissions
  SELECT ul.uid, ul.email, ul.role
  FROM user_login ul
  WHERE ul.role IN ('faculty', 'staff')
  AND NOT EXISTS (
    SELECT 1 FROM department_permission dp 
    WHERE dp.user_id = ul.id AND dp.is_active = true
  );
  ```
